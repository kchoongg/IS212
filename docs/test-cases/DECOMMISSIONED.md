# Decommissioned test cases and tests

Every manual test case and automated test that a change to the requirements has
made out of date, what replaced it, and why. The changes themselves are in
[docs/CHANGES.md](../CHANGES.md). How to retire a case is in
[README.md](README.md#retiring-or-updating-a-test-case).

- **Retired**: what the case checks no longer exists, or its steps can no longer be followed. Its sheet is renamed `RETIRED – TC<nn>` and moved to the end of the workbook, with every execution block kept. Its Summary row says what supersedes it.
- **Updated**: the acceptance criterion it checks still holds; only wording, values or a precondition in the case are out of date. The sheet stays where it is, with a `v2 (2026-10-19): …` note in row 1 saying what to read differently.

Nothing is deleted or renumbered. Decided on 2026-10-19 by comparing each case
with the stories' current acceptance criteria in Jira, starting from the
"Out-of-date cases" sheet of the Sprint 3 regression
([docs/regression/Sprint-3_Regression.xlsx](../regression/Sprint-3_Regression.xlsx)),
where the team listed the cases a later story had changed.

Totals: 17 manual test cases Retired, 67 Updated; 2 automated test files archived.
