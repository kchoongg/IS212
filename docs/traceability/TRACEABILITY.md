Column notes:

- **AC coverage type**, per AC: **A** Automated (a test is tagged with it), **M** Manual only (an Active or Updated test case links it, no automated test), **S** Superseded (replaced by a change; see [CHANGES.md](../CHANGES.md#superseded-acceptance-criteria)), **N** None. Only None is a gap.
- **Unit** counts unit tests and mocked-route tests (`src/app/api/__tests__`) separately. For the Sprint 1 research and design stories it reads **setup / research**: those tests check shared setup (formatting, components, the database client), not a feature.
- **Latest manual result** is the newest execution block of each Active test case, counted by result, with the newest date. Retired test cases are listed in [DECOMMISSIONED.md](../test-cases/DECOMMISSIONED.md).
- **Reviewer** is who submitted a GitHub review of the PR, other than its author; "none recorded" means nobody did, and says who merged it. **Linked bugs** are the Jira bugs linked to the story, and the tests tagged `[BUG-n]` under it.
- **Review evidence**, per PR: a link from [review-evidence.csv](review-evidence.csv) (for a review held outside GitHub, e.g. a recording), else **GitHub review** (someone other than the author submitted one), else **Merged by <name>** (someone other than the author merged it), else **none recorded**.
- Gaps are only checked for stories that are Done or in the active sprint.
