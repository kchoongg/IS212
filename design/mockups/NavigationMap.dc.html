Where the roles hand over — every hand-off raises a notification

Organiser → Ops → Coordinator

Submitting a request puts it in the assignment queue. Assigning a coordinator makes it theirs.

Coordinator ↔ Organiser

Clarifications and change requests loop through the Discussion tab until the coordinator approves or rejects.

Coordinator → Venue Staff & Technical Support

A booking request and an equipment request run in parallel. Both decisions land back on the Readiness tab.

Coordinator → Attendee

Confirming the event opens registration. A later significant change re-notifies everyone already registered.
